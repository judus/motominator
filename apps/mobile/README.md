# Motominator mobile app

React Native + Expo SDK 57 + Expo Router, targeting Android and iOS.
Follow the repository root README for installation and phone connectivity.
Install JavaScript dependencies at the workspace root.

`npm run dev:mobile` starts Expo. `npm run build:mobile` exports bundles for
Android, iOS and the optional Expo web preview; it does not build native binaries.
The dedicated browser app is `apps/web`.

The default Expo starter screens remain available for framework exploration.
